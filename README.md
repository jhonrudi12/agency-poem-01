# Agency — The Key

A poem about the handover of agency between a person and an AI agent: I hand over the key — the doing — and keep what matters, the choosing. The poem turns on the discovery that the choosing was never the smaller half of the bargain, and that a thousand open doors are one door when someone else picks which one. One governing image, the key, carried from the first line to the last.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt`.
